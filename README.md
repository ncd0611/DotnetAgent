# ProjectAgent

> **Central repository hosting specialized AI Agent Teams for software engineering ecosystems.**

---

## 📌 Overview

**ProjectAgent** is a multi-agent repository designed to aggregate specialized AI agent teams, rules, workflows, and domain-specific skills for software development. Each sub-project represents an autonomous, specialized team engineered to integrate seamlessly into AI coding assistants (such as Google Antigravity).

---

## 📂 Agent Teams

| Team | Domain / Stack | Status | Description |
| :--- | :--- | :---: | :--- |
| **[DotNetAgent](./DotNetAgent)** | C# / .NET Ecosystem | **Active / Production-Ready** | Universal .NET AI Core Team covering Legacy .NET Framework migration, modern .NET 8/9/10, ABP Framework, EF Core/Dapper, performance profiling, and enterprise architecture. |
| **[GameAgent](./GameAgent)** | Game Development | **In Development** | AI agent team tailored for game engines, mechanics, gameplay programming, and game asset pipelines. |

## 🚀 Getting Started

Each agent team is self-contained with its own specifications, rules, agent definitions, and automation scripts:

- To explore or install the **.NET AI Core Team**, see the [DotNetAgent README](./DotNetAgent/README.md).
- To run automated audits and tests on the agent teams:
  ```powershell
  # Test DotNetAgent
  cd DotNetAgent
  python tests/run_all.py
  ```
