# GameAgent

> **AI Agent Team specialized for Game Development.**

---

## 📌 Overview

`GameAgent` is currently in the planning and initial setup phase. It will provide specialized AI agents, rules, and skills for:
- Game Engine architectures (Unity, Unreal Engine, Godot, custom engines)
- Gameplay mechanics and state machines
- Asset pipeline optimization and performance profiling
- Shaders, graphics, and physics calculations
